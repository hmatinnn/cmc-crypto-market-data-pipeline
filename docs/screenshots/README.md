# Screenshots

Drop the images referenced by the main README here, using exactly these names:

| File | What to capture |
|---|---|
| `airflow-dags.png` | Airflow home page with the `cmc_*` pipelines enabled and recent green runs |
| `airflow-graph.png` | Graph view of one cadence chain: fetch → parse → load → dbt |
| `superset-overview.png` | The market overview dashboard |
| `grafana-monitoring.png` | Freshness / row count / DAG status panels |
| `ci-run.png` | A green GitHub Actions run showing all six jobs |

Take these **while the VPS is still running** — once it is decommissioned the
live UIs are gone, but the screenshots keep the project presentable.

Tips:

- Capture at a wide window size (1600px or more) so text stays readable.
- Crop out the browser chrome and anything containing tokens or hostnames.
- PNG for UI screenshots; keep each file under ~500KB.
